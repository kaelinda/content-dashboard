# V1.2 · Sage Studio 界面实现

## 基线与设计依据

基于 main `73fca79683181b31ecc054c4612eb5c8d1ca53a9`（V1.1.2）增量实现。以本次对话中确认的五张深绿／暖白效果图为视觉依据：工作台、内容编辑、信息源、产物中心、项目与权限管理。

保留现有 REST/MCP 契约、项目与 Agent 授权、数据库迁移、配置检查、版本规则和幂等保存。没有替换 001/002 迁移，没有清空或自动注入业务数据。样例只在隔离的浏览器测试库中显式创建。

## 设计到代码

| 设计要素               | 实际组件与行为                                                                           |
| ---------------------- | ---------------------------------------------------------------------------------------- |
| 深绿侧栏与通透暖白外壳 | CSS 渐变与轻量 backdrop-filter；无需图片背景、远程字体、图表依赖                         |
| 工作台统计卡片         | 实际 Agent 身份、项目、正文计数；请求标明“最近最多30条”，不冒充总量                      |
| Agent 管理 + 能力侧栏  | 从授权记录取数；只显示已授权／已停用，不捏造在线、空闲、运行中                           |
| 数据构成图             | 按来源／正文／产物实际记录数量绘制；不是采集渠道比例或流量增长                           |
| 信息源主从视图         | 类型筛选、已载入记录内搜索、排序、概览、原文、当前版本关联内容、快照下载、基于来源创建   |
| 产物主从视图           | 格式／正文新旧筛选、真实文件预览、绑定正文版本、配方、下载、发布登记                     |
| 项目与权限管理         | 项目筛选、Agent 搜索、授权状态筛选、权限详情、生成令牌、停用／启用、最近调用             |
| 内容编辑器             | 纸面层级、区块样式、工具栏、阅读预览、版本历史、来源卡片；保留原有保存状态机             |
| 手机端                 | 小屏不缩小桌面表格强塞；列表／详情切换，导航焦点约束、Escape关闭、焦点返回、关键44px按钮 |

截图中的曝光点击、增长率、成员数、配额、自动验证、自动发文、AI建议、WYSIWYG格式按钮、批量RSS导入、Word解析等未实现能力**没有作为可用功能伪造**。授权详情是只读说明，不绘制会误导人的“立即修改权限”开关。需要改变授权范围时，建立新身份并停用旧身份。

## 数据与安全边界

- 来源列表、产物列表的搜索和筛选作用于已载入记录；页面明确显示已载入／总计。可以继续加载更多；全库来源／内容检索仍用顶部搜索。
- `/api/sources/{id}` 增量提供 `related_contents`：最多100条、正文当前版本关联。该读取继续使用原接口鉴权，不是匿名数据接口。
- 选择另一来源时取消上一请求，避免迟到响应显示错记录；失败可重试。
- 产物预览只在选择后加载，限2MiB。HTML在无脚本的 sandbox iframe中呈现，并限制外部资源、表单和基础地址；图片使用临时对象URL，切换时撤销。
- 更大文件、视频及不支持的格式提供原文件下载，不编造缩略图或播放结果。文件格式检查仍不等于恶意软件扫描。
- 产物文件不可变；所有发布状态来自人工登记，不代表第三方平台已确认。
- 所有权威数据仍在服务端。界面筛选只是本次视图状态，不将正文持久化到 localStorage。
- 现有人工编辑器的手动保存、未确认请求重试和输入保护保持不变；没有宣称新增自动保存、离线恢复或完整富文本编辑。
- 不额外加载外部CDN／跟踪脚本／字体。弱化动画遵从 prefers-reduced-motion，缺少 backdrop-filter 时提供不透明背景。

## 验收

原有核心4项 + Agent5项端到端场景继续运行，只更新改版后的页面标题选择器。新增4项 Studio 场景在第三个独立数据目录运行，覆盖：

1. 真实数据的五个桌面页面截图、组件渲染、无未处理前端错误。
2. 来源筛选、原文读取、关联文章跳转、失败重试。
3. 产物格式／状态筛选、受限HTML预览、真实下载、Agent项目筛选与接入信息。
4. 390px手机布局、主从切换、搜索快捷键、菜单焦点返回、关键按钮尺寸、无页面横向溢出。

截图里的文字带“示例”，并由测试调用真实API写入。生产空库不会出现这些数据。通过结果以对应 GitHub Actions 为准；本地受管理浏览器若禁止 localhost，不以该环境阻断替代浏览器验证。原有领域、配置、数据库、客户端、生产构建与Docker检查继续保留。

## 工程结构

- `src/app/studio.css`：独立的主题与响应式覆盖。
- `src/components/studio/shared.tsx`：共享卡片、标题、搜索、身份与请求表。
- `src/components/studio/overview.tsx`：Agent-first工作台。
- `src/components/studio/sources.tsx`：来源主从工作区。
- `src/components/studio/artifacts.tsx`：产物预览与登记工作区。
- `src/components/agent-console.tsx`：沿用真实管理操作的新布局。
- `tests/e2e/studio.spec.ts`：实际界面与交互验收。

## 升级

先备份并停止旧应用，保留配置与数据目录，拉取代码后执行 `npm ci`、`npm run db:migrate`、`npm run build`、`npm start`。本版没有新数据库迁移。实际公网部署及第三方账号连接仍需要对应运行环境，不由界面改版自动完成。
