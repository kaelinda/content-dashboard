按本次对话中用户确认的五张绿色 / 暖白 UI 概念图，更新工作台、内容详情、信息源、产物与发布中心、项目与权限管理。

## 视觉实现

`src/app/studio.css` 是加载在原基础样式之后的统一 Studio 设计层；不以截图铺在页面上，也不依赖第三方图片、在线字体或新增 UI 框架。

- 深绿色渐变侧栏，选中项使用柔和高亮和细线。
- 暖白实体内容卡片；仅顶栏和编辑操作栏使用轻量背景模糊。
- 桌面端窗口式外框、统一圆角、边框、轻阴影和字体层次。
- 资料和输出采用主列表 + 上下文详情；在窄屏转为上下布局。
- 390px 手机布局、1024px 中间宽度、宽屏三列权限布局；触屏主按钮 44px 目标。
- 支持 reduced motion 与 forced colors，键盘焦点可见，弹窗与手机导航管理焦点。

## 数据真实性与安全

- 新增 `/api/studio` 仅允许所有者会话读取；匿名和 Agent Bearer 不能获取全库聚合。它不是新 Agent 工具。
- 聚合值来自实际数据库，而非首页最多 100 条的列表。列表搜索明确标注“已载入”，加载更多不被包装成全库检索；全局搜索沿用现有全文检索。
- 来源的“人工可信度”不是事实核验。导入成功不显示为自动验证成功。
- Agent 状态只显示已授权 / 已停用，不假装在线或运行中。权限详情只展示实际授权；修改范围需创建新身份并停用旧身份，不放无效开关。
- 发布仍为人工台账，不自动发文；不展示参考图中编造的曝光、互动、订阅配额和存储上限。
- 不添加未接通的 AI 编写、RSS 批量抓取、自动审核或平台分析按钮。
- HTML 预览使用无脚本 sandbox 和额外 CSP，禁止网络请求、脚本、表单和嵌套页面。图片 / 视频预览从真实私有文件字节读取，临时 Blob URL 在切换 / 退出时释放。
- 请求日志是现有记录的 JSON/MCP 操作，不能推导完整 API 流量或在线状态。

## 升级与边界

已有安装先备份并停止旧应用，拉取新版、`npm ci`、`npm run db:migrate`、`npm run build`、`npm start`。保留 `.env.local` 和 `.data`，不要重跑初始化或删除数据。此 UI 版本不新增迁移，不修改 Agent API 契约。

这是实际 Next.js UI 的改版，不代表已部署至用户公网服务器。不包含完整所见即所得编辑器、AI 自动写作、自动保存/离线队列、Webhook、任务 worker、自动发布或第三方账号联调。历史对比为真实正文的并排展示，不宣称语义 diff 或事实核验。
